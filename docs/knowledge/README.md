## 决定与复用边界

- [交付顺序](../../PLAN.md)：后端全部完成，再集中优化 UX，最后打包；未部署源码不能当作运行版交付。
- [架构复核](../../ARCHITECTURE-REVIEW.md)：参考框架的适用范围与差异，不把相似名称当作兼容保证。
- [Paperclip 有限源码复用](../../PAPERCLIP-REUSE.md)：固定上游来源与许可证，不接入另一任务或审批服务。
- [条件与循环](../../PRODUCT-DESIGN.md)：机械循环核清终止条件；创新迭代事先明确终止条件和最大尝试次数，任一达到即停，次数耗尽仍不满意转人工。unknown 等待补事实但不越过上限，停止不冒充成果完成；分类已定，功能未实现。
