## 六、已知限制与技术债务

1. **kimi ACP 未实现 `session/cancel`**：T3 停止按钮报错且 turn 停不掉（已多次实测），需报 Kimi 上游。
2. **specgraph 上游无 Windows 支持**：本地新增 `service_unsupported.go` stub（可回提上游）；镜像克隆有 CRLF 污染（全库已转 LF，GitHub 恢复后重拉核对）。
3. **T3 设置手写可能被覆盖**：`~/.t3/userdata/settings.json` 的手写 provider 配置在 T3 重写设置时可能丢失（UI 里手填一次即可）。
4. **`/wb` `/loop` 无鉴权**：仅绑 127.0.0.1 为前提（差异 D10）。
5. **claim 与包固化非单事务**：PrepareRun 中 claim 租约与 package/binding 写入分两个事务，中途失败会留租约（30 分钟自过期兜底）。
6. **未提交**：specgraph 扩展改动全部在工作树（无 git commit）；t3code fork 同理。上游更新时需人工 rebase。
7. **桌面 dev 模式**：`VITE_DEV_SERVER_URL` 下桌面不启内置 server 而要求 `T3CODE_PORT` 独占——外部进程占用该端口会报 401（本次已踩过一次，验证用临时 server 所致）。
